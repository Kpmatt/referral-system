📋 用意しておくもの

✅ 最低限必要なもの
  • 🦊 MetaMask（Web ウォレット）
    ご自身の暗号通貨を安全に保管・運用するためのウォレット。流動性プールの各認証操作はこのウォレットを介して行います。
  • 💻 パソコン
    プラットフォームのマイページを表示し、流動性プールの各種設定に使用します。運用資金の状況および手数料の確認もできます。
  • 📱 スマートフォン
    iPhoneでもAndroidでも可能。MetaMaskアプリをダウンロードして、プラットフォームと接続する際に必要です。
  • 💰 運用予定の暗号通貨
    初期設定の段階でMetaMaskに必要な量の暗号通貨を入れておきます。
🔶 状況により必要なもの
  • 🏦 日本の暗号通貨取引所アカウント
    例：OKCoin Japan、Coincheck など。日本円から暗号通貨を購入する場合、または外部ウォレットや取引所から両替して送る場合に必要。
  • 💳 クレジットカード
    MetaMask内で直接暗号通貨を購入する場合に必要。
  • 🪪 身分証明書
    暗号通貨購入の際に本人確認（KYC）のために必要。登録時のみ必要で、一度完了すれば以降は不要です。

他のウォレット・取引所からMetaMaskへ送金
方法 2 — 送金
  1. 1MetaMaskを開く → ネットワークを「Base」に切り替える
  2. 2「受け取る」をタップ → アドレス（0x...）をコピー
  3. 3送金元の取引所・ウォレットのアプリまたはウェブサイトを開き、ログインするスマホの場合はアプリを起動。PCの場合はブラウザで取引所のサイトにアクセスし、メールアドレスとパスワードでログインしてください。
  4. 4「送金」「出金」「Withdraw」などのメニューを探してタップ・クリックするメニューの場所は取引所によって異なります。画面下部・上部・ハンバーガーメニュー（三本線）の中などにあることが多いです。 ※ ETHをお持ちでない場合：まず「両替」「スワップ」「Convert」メニューを開き、保有中のUSDT・BTC等を「ETH」に変換してから送金へ進んでください。
  5. 5送金する通貨で「ETH」を選択する通貨の検索欄に「ETH」と入力すると見つかりやすいです。BTC・USDTなど他の通貨と間違えないよう注意してください。
  6. 6ネットワークで「Base」を選択する（Ethereum Mainnetではない）ネットワーク選択肢が表示されたら必ず「Base」を選択してください。「Ethereum」「ERC20」「BSC」などは別のネットワークです。Baseを選ぶことで手数料が安くなります。
  7. 7送金先アドレス欄に、コピーしたMetaMaskのBaseアドレスを貼り付けるアドレス入力欄を長押し（スマホ）またはCtrl+V（PC）で貼り付けます。貼り付け後、先頭と末尾のアドレスが合っているか目視で確認してください。
  8. 8送金額を入力し、手数料（ガス代）を確認してから送金を実行するBaseネットワークの送金手数料は通常$0.01〜$0.10程度と非常に安価です。「最大」「MAX」ボタンを使う場合、手数料分が差し引かれた額が送金されます。二段階認証（メール・SMS・アプリ）が求められたらコードを入力して完了してください。
  9. 9MetaMaskのBase ETH残高に反映されるのを確認する通常数分〜数時間で反映されます。MetaMaskアプリを開き、ネットワークがBaseになっている状態でETHの残高が増えていれば成功です。
🚨アドレスが一文字でも間違うと受け取れないため、前後にスペースが入っていたり違うアドレスになっていたりしていないかを確認の上、送付してください。
⚠️ネットワーク選択を間違えると資産が届きません。必ず「Base」を選択してください。送金手数料（ガス代）分の残高も確保しておきましょう。
💡Coinbase、Binance、OKX、Bybitなど主要取引所はBaseネットワークへの出金に対応しています。

MetaMaskをインストールしてから送金
事前準備 → 方法 2 — 送金
  1. 1App StoreまたはGoogle Playで「MetaMask」をインストール
  2. 2「新しいウォレットを作成」をタップ → パスワードを設定（8文字以上）パスワードはMetaMaskアプリを開くときに使います。忘れないようにメモしておきましょう。英数字・記号を組み合わせた強力なパスワードが推奨されます。
  3. 3シークレットリカバリーフレーズ（12単語）を紙に書いて安全な場所に保管し、順番通りに入力して確認するこのフレーズがあれば別のデバイスでも資産を復元できます。スクリーンショットや写真での保存は危険です。必ず紙に手書きし、金庫など安全な場所に保管してください。
  4. 4MetaMaskを開く → ネットワークを「Base」に切り替える
  5. 5受取アドレス（0x...）を表示してコピーする
  6. 6送金元の取引所・ウォレットを開いてログインし「送金」「出金」「Withdraw」などのメニューを開くETHをお持ちでない場合は先に「両替」「スワップ」機能で保有コインをETHに換金してください。
  7. 7通貨「ETH」を選択し、ネットワークを「Base」に設定するネットワークの選択肢が複数ある場合、必ず「Base」を選んでください。Ethereum Mainnet（ERC20）ではありません。
  8. 8送金先アドレスにコピーしたMetaMaskのアドレスを貼り付け、金額を入力して送金を実行するBaseネットワークのガス代（送金手数料）は通常$0.01〜$0.10程度です。二段階認証コードが求められたら入力して送金を完了させてください。
  9. 9MetaMaskのBase ETH残高に反映されていることを確認するMetaMaskアプリを開き、ネットワークが「Base」の状態でETH残高が増えていれば送金完了です。通常数分〜数時間かかります。
🚨アドレスが一文字でも間違うと受け取れないため、前後にスペースが入っていたり違うアドレスになっていたりしていないかを確認の上、送付してください。
⚠️リカバリーフレーズは絶対に他人に見せないでください。紛失すると資産を取り戻せません。

MetaMaskのクレジットカードでETHを購入
方法 1 — クレカ購入
  1. 1App StoreまたはGoogle Playで「MetaMask」をインストール
  2. 2「新しいウォレットを作成」をタップ → パスワードを設定（8文字以上）MetaMaskアプリを開くたびに使うパスワードです。英数字・記号を組み合わせた強力なものを設定し、必ずメモしておきましょう。
  3. 3シークレットリカバリーフレーズ（12単語）を紙に書いて安全な場所に保管し、確認入力を完了するこのフレーズはウォレットの鍵です。絶対に他人に見せず、スクリーンショットも厳禁です。紙に手書きして金庫などに保管してください。
  4. 4MetaMaskアプリで「購入」または「Buy」をタップする
  5. 5購入するトークンで「ETH」を選び、ネットワークを「Base」に選択するトークン一覧からETHを探してタップします。ネットワーク選択画面が出たら「Base」を選んでください。Ethereum Mainnetを選ぶと手数料が高くなるため注意が必要です。
  6. 6購入プロバイダー（Transak / MoonPay / Sardine など）を選択する各プロバイダーで手数料や対応カードが異なります。画面に表示される手数料を確認して選んでください。Transakは日本のカードに比較的対応しています。
  7. 7購入金額を入力し、クレジットカード情報を入力する最低購入額は$30〜$50程度です。カード番号・有効期限・セキュリティコード（CVV）を入力します。3Dセキュア（カード会社の本人認証）が求められることがあります。
  8. 8初回はKYC（本人確認）を完了するパスポートまたは運転免許証の写真と顔写真の撮影が求められます。審査は通常数分〜数十分で完了します。一度完了すれば次回以降は不要です。
  9. 9購入完了後、MetaMaskのBase ETH残高に反映されることを確認する通常数分〜数時間で反映されます。MetaMaskを開きネットワークが「Base」になっている状態でETH残高を確認してください。
💡手数料は3〜5%程度かかります。少額から試す場合は最低$30〜$50程度からが目安です。
⚠️KYCではパスポートまたは運転免許証が必要です。審査は通常数分〜数十分で完了します。

方法 3 — 国内取引所経由

下記ステップはあくまで一例です。既にお使いの国内取引所の口座をお持ちの場合はそちらをお使いいただくことも可能です。

■ STEP A　MetaMask インストール
  1. 1App StoreまたはGoogle Playで「MetaMask」をインストール
  2. 2「新しいウォレットを作成」をタップ → パスワードを設定（8文字以上）
  3. 3シークレットリカバリーフレーズ（12単語）を紙に書いて安全な場所に保管 → 順番通りに入力して確認
  4. 4ERC20（Ethereum Mainnet）の受取アドレスを確認してメモする
■ STEP B　OKCoin Japan 口座開設
  1. 1下記URLをコピーしてブラウザで検索、またはこちらをクリックしてOKCoin Japanの口座開設ページを開くhttps://www.okcoin.jp/account/join?invitation=386D31C&type=0→ 「口座開設」をクリックリンクをタップ・クリックすると別のタブ（ウィンドウ）でOKCoinの登録ページが開きます。
  2. 2メールアドレスを入力し、パスワードを設定してメール認証を完了する登録したメールアドレス宛に確認コードが届きます。メールを開いてコードをコピーし、画面の入力欄に貼り付けて認証を完了してください。迷惑メールフォルダも確認してみてください。
  3. 3本人確認（KYC）書類を提出するマイナンバーカードまたは運転免許証の表面・裏面を撮影してアップロードします。その後、スマホのカメラで顔写真（セルフィー）の撮影が求められます。画像は鮮明に撮影し、文字が読めることを確認してください。
  4. 4審査完了メールを受信したら（通常1〜3営業日）、二段階認証（2FA）を設定する審査完了メールが届いたらログインし、セキュリティ設定から二段階認証を有効にしてください。Google Authenticatorアプリの利用を推奨します。これで口座開設は完了です。
⚠️振込人名義はOKCoinの指定形式で入力してください。形式が違うと入金が反映されない場合があります。
💡OKCoin Japanは金融庁登録の国内取引所です。日本円での購入が安心かつ手数料も比較的安価です。
■ STEP C　日本円入金
  1. 1OKCoin Japanにログイン → 「資産」メニューをタップ → 「日本円入金」を選択するログイン後、画面下部または上部メニューの「資産」を開いてください。「日本円入金」ボタンをタップすると振込先情報が表示されます。
  2. 2表示された振込先銀行口座と振込人名義の形式をメモする銀行名・支店名・口座番号・口座名義が表示されます。振込人名義は「カタカナ氏名＋OKCoin指定の番号」などの形式になっています。この形式と異なると入金が反映されないため必ず確認してください。
  3. 3自分の銀行アプリまたはネットバンキングを開き、表示された口座に振り込む振込先口座番号と振込人名義（指定形式）を正確に入力してください。振込手数料は自己負担となります。ATMからの振り込みも可能ですが、ネットバンキングの方が便利です。
  4. 4OKCoinの資産画面で日本円残高が増えていることを確認する通常当日〜翌営業日中に反映されます。反映後、OKCoinから確認メールが届く場合もあります。
■ STEP D　ETH購入
  1. 1「資産」→「振替」を開き、入出金口座から取引口座へ日本円を振替するOKCoinでは購入操作に「取引口座」の残高が必要です。「振替元：入出金口座」「振替先：取引口座」「通貨：JPY」を選択し、振替金額を入力して実行してください。
  2. 2「取引所」メニューをタップ・クリックし、「ETH/JPY」の取引ペアを選択する画面上部または下部メニューから「取引所」を選択します。通貨ペア一覧が表示されたら検索欄に「ETH」と入力するか一覧から「ETH/JPY」を探してタップしてください。
  3. 3注文タイプを「指値」から「成行」に変更する「指値」は価格を自分で指定する方法、「成行」は現在の市場価格ですぐに購入できる方法です。初めての方は「成行」を選ぶと簡単に購入できます。
  4. 4購入数量をJPY建てで入力するか、割合（25% / 50% / 75% / 100%）を選択し「ETHを購入」をタップする「100%」を選ぶと取引口座の全額でETHを購入します。購入確認画面が表示されたら内容を確認して「確定」をタップしてください。
  5. 5購入完了後、「資産」→「振替」から取引口座のETHを入出金口座へ振替する「振替元：取引口座」「振替先：入出金口座」「通貨：ETH」を選択し、全額を振替してください。この振替が完了しないと次の出庫（送金）操作ができません。
■ STEP E　MetaMaskのERC20アドレスを確認
ℹ️OKCoinはBaseネットワークに対応していないため、ERC20（Ethereum Mainnet）で送金します。MetaMaskに届いたETHはSwap→Bridgeでそのまま運用できます。
  1. 1MetaMaskを開いてEthereum Mainnet（ERC20）ネットワークを確認・切り替える
  2. 2受取画面を開いてERC20アドレス（0x...）をコピー・メモする表示されたアドレスをタップしてコピー（スマホ）またはクリックしてコピー（PC）します。このアドレスをOKCoinの出庫先として使用します。メモ帳などに貼り付けておくと安全です。
■ STEP F　OKCoinからMetaMaskへ出庫（送金）
  1. 1OKCoinで「資産」→「暗号資産出庫」を開き「ETH」を選択する「暗号資産出庫」は資産を外部ウォレットに送金する機能です。メニューから選択すると出庫する通貨の一覧が表示されます。「ETH」を選んでください。
  2. 2ネットワークで「ERC20」を選択するOKCoin JapanはBaseネットワークに対応していないため、必ず「ERC20」を選んでください。「ERC20」=「Ethereum Mainnet」です。間違えて他のネットワークを選ぶと資産が届きません。
  3. 3送金先アドレス欄にSTEP EでコピーしたMetaMaskのERC20アドレスを貼り付ける入力欄を長押し（スマホ）またはCtrl+V（PC）でアドレスを貼り付けます。貼り付け後、アドレスの先頭数文字・末尾数文字がコピー元と一致しているか必ず目視で確認してください。
    🚨 アドレスが一文字でも間違うと受け取れないため、前後にスペースが入っていたり違うアドレスになっていたりしていないかを確認の上、送付してください。
  4. 4画面に表示される利用規約・注意事項のチェックボックスすべてにチェックを入れるOKCoinは出庫前に複数の注意事項への同意を求めます。内容をよく読み、すべてチェックしてください。
  5. 5出庫数量を入力し、二段階認証コードを入力して「出庫する」をタップ・クリックする出庫数量はETH単位で入力します。「全額」ボタンで入出金口座の全ETHを選択できます。二段階認証コードはGoogle AuthenticatorアプリまたはSMS・メールで届いた番号を入力してください。
  6. 6MetaMaskのEthereum Mainnet残高にETHが反映されることを確認する通常数分〜数十分でMetaMaskに反映されます。MetaMaskを開き、ネットワークが「Ethereum Mainnet」の状態でETH残高が増えていれば出庫完了です。Swap→BridgeでBaseネットワークへの変換も可能です。
